1. Count Odd Numbers from A to B

Easy ⏱️ 10-15 min

Problem:

Write a program that counts how many odd numbers exist in the range from A to B (inclusive).

Requirements:

  • Get two integers A and B from user input
  • Display the total count of odd numbers

Example:

Input: A = 1, B = 10
Output: There are 5 odd numbers (1, 3, 5, 7, 9)

Input: A = 10, B = 20
Output: There are 5 odd numbers (11, 13, 15, 17, 19)

2. Sum of Numbers from A to B

Easy ⏱️ 10-15 min

Problem:

Write a program that calculates the sum of all numbers in the range from A to B (inclusive).

Requirements:

  • Get two integers A and B from user input
  • Display the sum result

Example:

Input: A = 1, B = 5
Output: Sum = 15 (1+2+3+4+5)

Input: A = 10, B = 15
Output: Sum = 75 (10+11+12+13+14+15)

3. Count Numbers Divisible by 3

Easy ⏱️ 10-15 min

Problem:

Write a program that counts and displays all numbers divisible by 3 in the range from A to B (inclusive).

Requirements:

  • Get two integers A and B from user input
  • Display all numbers found and the total count

Example:

Input: A = 1, B = 10
Output: Numbers divisible by 3: 3, 6, 9
Count: 3

Input: A = 10, B = 20
Output: Numbers divisible by 3: 12, 15, 18
Count: 3

4. Sum of Digits

Easy ⏱️ 15-20 min

Problem:

Write a program that calculates the sum of all digits in a positive integer using a loop.

Requirements:

  • Get a positive integer from user input
  • Display the sum of all digits
  • Handle special case for 0 (sum is 0)

Example:

Input: 12345
Output: Sum of digits = 15 (1+2+3+4+5)

Input: 999
Output: Sum of digits = 27 (9+9+9)

Input: 0
Output: Sum of digits = 0

5. Count Even Digits in a Number

Easy ⏱️ 15-20 min

Problem:

Write a program that counts how many even digits are in a positive integer.

Requirements:

  • Get a positive integer from user input
  • Display the count of even digits

Example:

Input: 123456
Output: Even digits: 2, 4, 6
Count: 3 even digits

Input: 987654
Output: Even digits: 8, 6, 4
Count: 3 even digits

Input: 13579
Output: Count: 0 even digits

6. Check Prime Number

Easy ⏱️ 15-20 min

Problem:

Write a program that checks whether a given positive integer is a prime number or not. A prime number is a number greater than 1 that has no divisors other than 1 and itself.

Requirements:

  • Get a positive integer from user input
  • Display whether the number is prime or not
  • Handle special cases: numbers less than 2 are not prime

Example:

Input: 7
Output: 7 is a prime number

Input: 12
Output: 12 is not a prime number (divisible by 2, 3, 4, 6)

Input: 2
Output: 2 is a prime number

Input: 1
Output: 1 is not a prime number
