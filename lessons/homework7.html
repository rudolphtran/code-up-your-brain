🟢 DỄ

Bài tập Dễ (1-8)

Tổng, đếm, tìm max/min, tổng hàng/cột và đường chéo trên ma trận

1. Tổng Ma Trận

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tong_ma_tran(matrix) trả về tổng tất cả các phần tử trong ma trận.

Ví dụ Input/Output:

print(tong_ma_tran([[1, 2], [3, 4]]))   # Output: 10
print(tong_ma_tran([[5]]))               # Output: 5
print(tong_ma_tran([]))                  # Output: 0

2. Đếm Số Chẵn Trong Ma Trận

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm dem_so_chan_matrix(matrix) trả về số lượng phần tử chẵn trong ma trận.

Ví dụ Input/Output:

print(dem_so_chan_matrix([[1, 2, 3], [4, 5, 6]]))   # Output: 3
print(dem_so_chan_matrix([[1, 3, 5]]))               # Output: 0
print(dem_so_chan_matrix([[2, 4], [6, 8]]))          # Output: 4

3. Tìm Giá Trị Lớn Nhất

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tim_max_matrix(matrix) trả về một tuple (gia_tri, hang, cot) của phần tử lớn nhất (lấy vị trí xuất hiện đầu tiên nếu có nhiều phần tử bằng nhau).

Ví dụ Input/Output:

print(tim_max_matrix([[3, 8, 1], [9, 2, 7]]))   # Output: (9, 1, 0)
print(tim_max_matrix([[5]]))                     # Output: (5, 0, 0)
print(tim_max_matrix([[1, 9], [9, 1]]))          # Output: (9, 0, 1)

4. Tổng Từng Hàng

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tong_tung_hang(matrix) trả về danh sách tổng các phần tử của mỗi hàng.

Ví dụ Input/Output:

print(tong_tung_hang([[1, 2, 3], [4, 5, 6]]))   # Output: [6, 15]
print(tong_tung_hang([[10]]))                    # Output: [10]
print(tong_tung_hang([[1, 1], [2, 2], [3, 3]]))  # Output: [2, 4, 6]

5. Tổng Từng Cột

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tong_tung_cot(matrix) trả về danh sách tổng các phần tử của mỗi cột.

Ví dụ Input/Output:

print(tong_tung_cot([[1, 2, 3], [4, 5, 6]]))   # Output: [5, 7, 9]
print(tong_tung_cot([[1], [2], [3]]))           # Output: [6]
print(tong_tung_cot([[1, 2], [3, 4], [5, 6]]))  # Output: [9, 12]

6. Tổng Đường Chéo Chính

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tong_duong_cheo_chinh(matrix) trả về tổng các phần tử trên đường chéo chính của ma trận vuông.

Ví dụ Input/Output:

print(tong_duong_cheo_chinh([[1, 2], [3, 4]]))                  # Output: 5
print(tong_duong_cheo_chinh([[5]]))                              # Output: 5
print(tong_duong_cheo_chinh([[1, 2, 3], [4, 5, 6], [7, 8, 9]]))  # Output: 15

7. Đếm Số Lần Xuất Hiện

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm dem_xuat_hien(matrix, x) đếm số lần giá trị x xuất hiện trong ma trận.

Ví dụ Input/Output:

print(dem_xuat_hien([[1, 2, 2], [3, 2, 1]], 2))   # Output: 3
print(dem_xuat_hien([[1, 1], [1, 1]], 5))          # Output: 0
print(dem_xuat_hien([[7]], 7))                     # Output: 1

8. Hàng Có Tổng Lớn Nhất

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm hang_co_tong_lon_nhat(matrix) trả về chỉ số của hàng có tổng các phần tử lớn nhất (lấy hàng đầu tiên nếu có nhiều hàng bằng nhau).

Ví dụ Input/Output:

print(hang_co_tong_lon_nhat([[1, 2], [3, 4], [0, 1]]))   # Output: 1
print(hang_co_tong_lon_nhat([[10]]))                      # Output: 0
print(hang_co_tong_lon_nhat([[5, 5], [1, 1], [5, 5]]))    # Output: 0
🟡 TRUNG BÌNH

Bài tập Trung bình (9-11)

Kiểm tra tính chất và biến đổi ma trận đòi hỏi tư duy logic nhiều hơn

9. Kiểm Tra Ma Trận Đối Xứng

Trung bình ⏱️ 15-20 phút

Bài toán:

Viết hàm la_doi_xung(matrix) trả về True nếu ma trận vuông đối xứng qua đường chéo chính (matrix[i][j] == matrix[j][i] với mọi i, j), ngược lại trả về False.

Ví dụ Input/Output:

print(la_doi_xung([[1, 2, 3], [2, 5, 6], [3, 6, 9]]))   # Output: True
print(la_doi_xung([[1, 2], [3, 4]]))                     # Output: False
print(la_doi_xung([[7]]))                                # Output: True

10. Chuyển Vị Ma Trận

Trung bình ⏱️ 15-20 phút

Bài toán:

Viết hàm chuyen_vi(matrix) trả về ma trận chuyển vị (đổi hàng thành cột), không dùng zip().

Ví dụ Input/Output:

print(chuyen_vi([[1, 2, 3], [4, 5, 6]]))   # Output: [[1, 4], [2, 5], [3, 6]]
print(chuyen_vi([[1], [2], [3]]))          # Output: [[1, 2, 3]]
print(chuyen_vi([[5]]))                    # Output: [[5]]

11. Tìm Điểm Yên Ngựa

Trung bình ⏱️ 15-20 phút

Bài toán:

Viết hàm tim_diem_yen_ngua(matrix) trả về giá trị của phần tử vừa là nhỏ nhất trong hàng của nó, vừa là lớn nhất trong cột của nó. Nếu không có, trả về None.

Ví dụ Input/Output:

print(tim_diem_yen_ngua([[3, 2, 1], [6, 5, 4], [9, 8, 7]]))   # Output: 7
print(tim_diem_yen_ngua([[1, 2], [3, 1]]))                     # Output: None
print(tim_diem_yen_ngua([[5]]))                                # Output: 5
🔴 KHÓ

Bài tập Khó (12-13)

Xoay ma trận và duyệt ma trận theo hình xoắn ốc

12. Xoay Ma Trận Ngược Chiều Kim Đồng Hồ

Khó ⏱️ 25-30 phút

Bài toán:

Viết hàm xoay_nguoc_kim_dong_ho(matrix) xoay một ma trận vuông 90 độ ngược chiều kim đồng hồ mà không dùng thư viện có sẵn.

Ví dụ Input/Output:

print(xoay_nguoc_kim_dong_ho([[1, 2, 3], [4, 5, 6], [7, 8, 9]]))
# Output: [[3, 6, 9], [2, 5, 8], [1, 4, 7]]
print(xoay_nguoc_kim_dong_ho([[1, 2], [3, 4]]))
# Output: [[2, 4], [1, 3]]
print(xoay_nguoc_kim_dong_ho([[5]]))
# Output: [[5]]

13. Duyệt Ma Trận Theo Hình Xoắn Ốc

Khó ⏱️ 25-30 phút

Bài toán:

Viết hàm duyet_xoan_oc(matrix) trả về danh sách các phần tử của ma trận (không nhất thiết vuông) theo thứ tự duyệt xoắn ốc từ ngoài vào trong, theo chiều kim đồng hồ.

Ví dụ Input/Output:

print(duyet_xoan_oc([[1, 2, 3], [4, 5, 6], [7, 8, 9]]))
# Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
print(duyet_xoan_oc([[1, 2, 3, 4], [5, 6, 7, 8]]))
# Output: [1, 2, 3, 4, 8, 7, 6, 5]
print(duyet_xoan_oc([[1]]))
# Output: [1]
🟣 TỔNG HỢP

Bài tập Tổng hợp (14-15)

Kết hợp ma trận với hàm và vòng lặp để giải các bài toán thực tế

14. Cộng Hai Ma Trận

Tổng hợp ⏱️ 30-40 phút

Bài toán:

Viết hàm cong_hai_ma_tran(a, b) (Bài 5: Hàm) nhận vào hai ma trận cùng kích thước và trả về ma trận tổng theo từng phần tử.

Ví dụ Input/Output:

print(cong_hai_ma_tran([[1, 2], [3, 4]], [[5, 6], [7, 8]]))
# Output: [[6, 8], [10, 12]]
print(cong_hai_ma_tran([[1]], [[9]]))
# Output: [[10]]
print(cong_hai_ma_tran([[0, 0]], [[1, 1]]))
# Output: [[1, 1]]

15. Đếm Cặp Quân Hậu Tấn Công Nhau

Tổng hợp ⏱️ 30-40 phút

Bài toán:

Viết hàm dem_cap_hau_tan_cong(positions) (Bài 5: Hàm) nhận vào danh sách vị trí (hang, cot) của các quân hậu, dùng vòng lặp lồng (Bài 4) để đếm số cặp quân hậu tấn công nhau (cùng hàng, cùng cột, hoặc cùng đường chéo).

Ví dụ Input/Output:

print(dem_cap_hau_tan_cong([(0, 0), (1, 1), (0, 4)]))   # Output: 2
print(dem_cap_hau_tan_cong([(0, 0), (2, 1)]))            # Output: 0
print(dem_cap_hau_tan_cong([(0, 0), (1, 0), (2, 0)]))    # Output: 3
