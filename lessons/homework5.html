1. Tính Tổng Hai Số

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tinh_tong(a, b) nhận vào hai số và trả về tổng của chúng.

Ví dụ Input/Output:

print(tinh_tong(5, 3))    # Output: 8
print(tinh_tong(10, 20))  # Output: 30
print(tinh_tong(-5, 5))   # Output: 0

2. Tìm Số Lớn Nhất

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tim_max(a, b, c) nhận vào ba số và trả về số lớn nhất.

Ví dụ Input/Output:

print(tim_max(5, 10, 3))   # Output: 10
print(tim_max(15, 15, 10)) # Output: 15
print(tim_max(-5, -2, -8)) # Output: -2

3. Kiểm Tra Số Chẵn

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm la_so_chan(n) kiểm tra số n có chẵn không. Trả về True/False.

Ví dụ Input/Output:

print(la_so_chan(4))   # Output: True
print(la_so_chan(7))   # Output: False
print(la_so_chan(0))   # Output: True

4. Tính Giai Thừa

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm giai_thua(n) tính n! = n × (n-1) × ... × 1.

Ví dụ Input/Output:

print(giai_thua(5))  # Output: 120
print(giai_thua(3))  # Output: 6
print(giai_thua(0))  # Output: 1

5. Đảo Ngược Chuỗi

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm dao_nguoc(chuoi) trả về chuỗi đảo ngược.

Ví dụ Input/Output:

print(dao_nguoc("hello"))   # Output: "olleh"
print(dao_nguoc("Python"))  # Output: "nohtyP"
print(dao_nguoc("12345"))   # Output: "54321"

6. Đếm Ký Tự

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm dem_ky_tu(chuoi) trả về số lượng ký tự trong chuỗi.

Ví dụ Input/Output:

print(dem_ky_tu("hello"))       # Output: 5
print(dem_ky_tu("Python 3.12")) # Output: 12
print(dem_ky_tu(""))            # Output: 0

7. Diện Tích HCN

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm dien_tich_hcn(dai, rong) tính diện tích hình chữ nhật.

Ví dụ Input/Output:

print(dien_tich_hcn(5, 3))   # Output: 15
print(dien_tich_hcn(10, 10)) # Output: 100
print(dien_tich_hcn(7, 2))   # Output: 14

8. Kiểm Tra Năm Nhuận

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm la_nam_nhuan(nam) kiểm tra năm nhuận. Chia hết cho 4 nhưng không chia hết cho 100, hoặc chia hết cho 400.

Ví dụ Input/Output:

print(la_nam_nhuan(2024))  # Output: True
print(la_nam_nhuan(2023))  # Output: False
print(la_nam_nhuan(2000))  # Output: True
print(la_nam_nhuan(1900))  # Output: False

9. Tổng Danh Sách

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tong_list(danh_sach) tính tổng các số trong danh sách.

Ví dụ Input/Output:

print(tong_list([1, 2, 3, 4, 5]))  # Output: 15
print(tong_list([10, 20, 30]))     # Output: 60
print(tong_list([]))               # Output: 0

10. Tìm Giá Trị Nhỏ Nhất

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tim_min(danh_sach) tìm số nhỏ nhất trong danh sách.

Ví dụ Input/Output:

print(tim_min([5, 2, 9, 1, 7]))  # Output: 1
print(tim_min([10, 20, 5, 15]))  # Output: 5
print(tim_min([-5, -2, -10]))    # Output: -10

11. Chuyển F sang C

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm fahrenheit_sang_celsius(f) chuyển độ F sang C. Công thức: C = (F - 32) × 5/9

Ví dụ Input/Output:

print(fahrenheit_sang_celsius(32))   # Output: 0.0
print(fahrenheit_sang_celsius(212))  # Output: 100.0
print(fahrenheit_sang_celsius(98.6)) # Output: 37.0

12. Kiểm Tra Số

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm kiem_tra_so(n) trả về "Dương" nếu n > 0, "Âm" nếu n < 0, "Không" nếu n = 0.

Ví dụ Input/Output:

print(kiem_tra_so(5))    # Output: "Dương"
print(kiem_tra_so(-3))   # Output: "Âm"
print(kiem_tra_so(0))    # Output: "Không"

13. Tính Lũy Thừa

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm luy_thua(co_so, so_mu) tính lũy thừa (co_so ^ so_mu).

Ví dụ Input/Output:

print(luy_thua(2, 3))   # Output: 8
print(luy_thua(5, 2))   # Output: 25
print(luy_thua(10, 0))  # Output: 1

14. Đếm Chữ Số

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm dem_chu_so(n) đếm số lượng chữ số trong số nguyên n.

Ví dụ Input/Output:

print(dem_chu_so(12345))  # Output: 5
print(dem_chu_so(999))    # Output: 3
print(dem_chu_so(7))      # Output: 1

15. Kiểm Tra Palindrome

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm la_palindrome(chuoi) kiểm tra chuỗi có đọc xuôi ngược giống nhau không.

Ví dụ Input/Output:

print(la_palindrome("madam"))    # Output: True
print(la_palindrome("racecar"))  # Output: True
print(la_palindrome("hello"))    # Output: False
print(la_palindrome("12321"))    # Output: True
