1. Ma trận là gì?

Ma trận (mảng hai chiều) là một bảng dữ liệu gồm nhiều hàng và nhiều cột. Trong Python, ta cài đặt ma trận bằng một list chứa các list con, mỗi list con tương ứng với một hàng.

Khi nào cần dùng ma trận?

  • Dữ liệu dạng bảng: bảng điểm nhiều môn, bảng cờ vua, ảnh (pixel).
  • Lưới (grid): bản đồ trò chơi, mê cung, sơ đồ chỗ ngồi.
  • Thống kê nhiều chiều: lượt like theo album và theo ngày, doanh số theo tháng và theo cửa hàng.

Ví dụ: Không dùng ma trận vs Dùng ma trận

❌ Không dùng ma trận
row1 = [8, 9, 7]
row2 = [6, 10, 8]
row3 = [9, 9, 10]
# Muon lay diem hang 2, cot 3 phai nho ten bien
print(row2[2])
✅ Dùng ma trận (list trong list)
scores = [
    [8, 9, 7],
    [6, 10, 8],
    [9, 9, 10]
]
print(scores[1][2])  # 8
📦

2. Khởi tạo và truy cập phần tử

Cú pháp cơ bản

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(matrix[0][0])   # 1 (hang 0, cot 0)
print(matrix[1][2])   # 6 (hang 1, cot 2)
print(matrix[-1][-1])  # 9 (phan tu cuoi cung)

Ma trận được truy cập bằng hai chỉ số: matrix[i][j], trong đó i là chỉ số hàng và j là chỉ số cột, đều bắt đầu từ 0.

Tạo ma trận rỗng kích thước n hàng x m cột

n, m = 3, 4

# Dung list comprehension - moi hang la 1 list doc lap
matrix = [[0] * m for _ in range(n)]

matrix[1][2] = 5
print(matrix)
# [[0, 0, 0, 0], [0, 0, 5, 0], [0, 0, 0, 0]]

⚠️ Lỗi thường gặp

Viết [[0] * m] * n sẽ tạo ra n hàng nhưng cùng tham chiếu đến MỘT list, sửa 1 phần tử sẽ làm thay đổi cả cột đó ở mọi hàng. Luôn dùng list comprehension [[0] * m for _ in range(n)] để tạo các hàng độc lập.

🔁

3. Duyệt ma trận và tính toán

Duyệt ma trận cần hai vòng lặp lồng nhau: vòng ngoài duyệt từng hàng, vòng trong duyệt từng cột trong hàng đó.

Ví dụ: Tính tổng toàn bộ ma trận

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

total = 0
for row in matrix:
    for value in row:
        total += value

print(total)  # 45

Ví dụ: Tổng từng hàng và tổng từng cột

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
n, m = len(matrix), len(matrix[0])

# Tong tung hang
for i in range(n):
    print(f"Tong hang {i}:", sum(matrix[i]))

# Tong tung cot
for j in range(m):
    col_sum = 0
    for i in range(n):
        col_sum += matrix[i][j]
    print(f"Tong cot {j}:", col_sum)
📐

4. Ma trận vuông và đường chéo

Ma trận vuông có số hàng bằng số cột (n x n). Đường chéo chính gồm các phần tử matrix[i][i], đường chéo phụ gồm các phần tử matrix[i][n-1-i].

Ví dụ: Tổng đường chéo chính và đường chéo phụ

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
n = len(matrix)

main_diag = 0
anti_diag = 0
for i in range(n):
    main_diag += matrix[i][i]
    anti_diag += matrix[i][n - 1 - i]

print("Duong cheo chinh:", main_diag)  # 1 + 5 + 9 = 15
print("Duong cheo phu:", anti_diag)    # 3 + 5 + 7 = 15
🌀

5. Xoay ma trận và ma trận xoắn ốc

Đây là hai kỹ thuật nâng cao thường gặp trong đề thi: xoay ma trận vuông 90 độ và duyệt ma trận theo đường xoắn ốc từ ngoài vào trong.

Ví dụ: Xoay ma trận vuông 90 độ theo chiều kim đồng hồ

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
n = len(matrix)

rotated = [[0] * n for _ in range(n)]
for i in range(n):
    for j in range(n):
        rotated[j][n - 1 - i] = matrix[i][j]

print(rotated)
# [[7, 4, 1], [8, 5, 2], [9, 6, 3]]

Ví dụ: Duyệt ma trận theo hình xoắn ốc

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

top, bottom = 0, len(matrix) - 1
left, right = 0, len(matrix[0]) - 1
result = []

while top <= bottom and left <= right:
    for j in range(left, right + 1):
        result.append(matrix[top][j])
    top += 1

    for i in range(top, bottom + 1):
        result.append(matrix[i][right])
    right -= 1

    if top <= bottom:
        for j in range(right, left - 1, -1):
            result.append(matrix[bottom][j])
        bottom -= 1

    if left <= right:
        for i in range(bottom, top - 1, -1):
            result.append(matrix[i][left])
        left += 1

print(result)  # [1, 2, 3, 6, 9, 8, 7, 4, 5]

6. Bài toán ứng dụng

Áp dụng ma trận vào hai bài toán quen thuộc: bàn cờ vua và bảng thống kê lượt thích trên mạng xã hội.

Ví dụ: Đếm số ô bị hậu (queen) tấn công trên bàn cờ

Cho vị trí một quân hậu trên bàn cờ 8x8, đánh dấu tất cả các ô mà quân hậu có thể tấn công (cùng hàng, cùng cột, cùng đường chéo). 

size = 8
board = [[0] * size for _ in range(size)]
qr, qc = 3, 4  # vi tri quan hau (hang, cot)

for i in range(size):
    for j in range(size):
        same_row = (i == qr)
        same_col = (j == qc)
        same_diag = (abs(i - qr) == abs(j - qc))
        if same_row or same_col or same_diag:
            board[i][j] = 1

attacked_cells = sum(row.count(1) for row in board) - 1  # tru o hau dang dung
print("So o bi tan cong:", attacked_cells)

Ví dụ: Thống kê lượt like album ảnh

Ma trận likes[i][j] lưu số lượt like của ảnh thứ j trong album thứ i. Tìm album có tổng lượt like cao nhất. 

likes = [
    [120, 45, 300],   # Album 0
    [80, 95, 60, 40], # Album 1
    [500, 220]        # Album 2
]

best_album = 0
best_total = 0
for i in range(len(likes)):
    total = sum(likes[i])
    if total > best_total:
        best_total = total
        best_album = i

print("Album nhieu like nhat:", best_album, "voi", best_total, "likes")

7. Bài tập thực hành

Bài tập 1: Tổng ma trận

Viết chương trình tính tổng tất cả các phần tử trong một ma trận.

matrix = [[1, 2], [3, 4], [5, 6]]
# TODO: in ra tong cac phan tu cua matrix
💡 Show Solution 
matrix = [[1, 2], [3, 4], [5, 6]]
total = sum(sum(row) for row in matrix)
print(total)  # 21

Bài tập 2: Tìm phần tử lớn nhất

Cho ma trận số nguyên, tìm giá trị lớn nhất và vị trí (hàng, cột) của nó.

matrix = [[3, 8, 1], [9, 2, 7], [4, 6, 5]]
# TODO: tim gia tri lon nhat va vi tri (hang, cot)
💡 Show Solution 
matrix = [[3, 8, 1], [9, 2, 7], [4, 6, 5]]
best_val = matrix[0][0]
best_pos = (0, 0)

for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        if matrix[i][j] > best_val:
            best_val = matrix[i][j]
            best_pos = (i, j)

print(best_val, best_pos)  # 9 (1, 0)

Bài tập 3: Tổng từng hàng

Viết chương trình in ra tổng các phần tử của từng hàng trong ma trận.

matrix = [[1, 2, 3], [4, 5, 6]]
# TODO: in ra tong cua tung hang
💡 Show Solution 
matrix = [[1, 2, 3], [4, 5, 6]]
for i, row in enumerate(matrix):
    print(f"Hang {i}:", sum(row))
# Hang 0: 6
# Hang 1: 15

Bài tập 4: Ma trận đối xứng

Kiểm tra một ma trận vuông có đối xứng qua đường chéo chính hay không (matrix[i][j] == matrix[j][i] với mọi i, j).

matrix = [[1, 2, 3], [2, 5, 6], [3, 6, 9]]
# TODO: kiem tra doi xung
💡 Show Solution 
matrix = [[1, 2, 3], [2, 5, 6], [3, 6, 9]]
n = len(matrix)
is_symmetric = True

for i in range(n):
    for j in range(n):
        if matrix[i][j] != matrix[j][i]:
            is_symmetric = False

print(is_symmetric)  # True

🏆 Thử thách: Xoay ma trận thủ công

Viết chương trình xoay một ma trận vuông 90 độ theo chiều kim đồng hồ mà không dùng zip() hay thư viện có sẵn, chỉ dùng vòng lặp. 

matrix = [[1, 2], [3, 4]]
# TODO: xoay matrix 90 do theo chieu kim dong ho
💡 Show Solution 
matrix = [[1, 2], [3, 4]]
n = len(matrix)
rotated = [[0] * n for _ in range(n)]

for i in range(n):
    for j in range(n):
        rotated[j][n - 1 - i] = matrix[i][j]

print(rotated)  # [[3, 1], [4, 2]]
