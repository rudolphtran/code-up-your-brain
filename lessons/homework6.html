Bài tập Dễ (1-17)

Tập trung vào duyệt mảng, tìm kiếm, thống kê cơ bản và làm quen với chuỗi

1. Tính Tổng Mảng

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tong_mang(arr) nhận vào một mảng số nguyên và trả về tổng các phần tử.

Ví dụ Input/Output:

print(tong_mang([1, 2, 3, 4]))    # Output: 10
print(tong_mang([10, -2, 5]))     # Output: 13
print(tong_mang([]))              # Output: 0

2. Đếm Số Chẵn

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm dem_so_chan(arr) trả về số lượng phần tử chẵn trong mảng.

Ví dụ Input/Output:

print(dem_so_chan([1, 2, 3, 4, 5, 6]))   # Output: 3
print(dem_so_chan([1, 3, 5]))            # Output: 0
print(dem_so_chan([2, 4, 8]))            # Output: 3

3. Tìm Giá Trị Lớn Nhất

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm tim_max_mang(arr) trả về phần tử lớn nhất trong mảng (giả sử mảng không rỗng).

Ví dụ Input/Output:

print(tim_max_mang([7, 2, 9, 4]))        # Output: 9
print(tim_max_mang([-5, -2, -8]))        # Output: -2
print(tim_max_mang([10]))                # Output: 10

4. Kiểm Tra Tồn Tại

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm co_trong_mang(arr, x) trả về True nếu x có trong mảng, ngược lại trả về False.

Ví dụ Input/Output:

print(co_trong_mang([3, 8, 1, 6], 8))   # Output: True
print(co_trong_mang([3, 8, 1, 6], 5))   # Output: False
print(co_trong_mang([], 1))             # Output: False

5. Tính Trung Bình Cộng

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm trung_binh_cong(arr) trả về giá trị trung bình của mảng. Nếu mảng rỗng, trả về 0.

Ví dụ Input/Output:

print(trung_binh_cong([2, 4, 6, 8]))   # Output: 5.0
print(trung_binh_cong([10, 20]))       # Output: 15.0
print(trung_binh_cong([]))             # Output: 0

Dễ ⏱️ 5-10 phút

Ví dụ Input/Output:

8. Đảo Ngược Mảng

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm dao_nguoc_mang(arr) trả về mảng mới theo thứ tự ngược lại (không dùng hàm có sẵn).

Ví dụ Input/Output:

print(dao_nguoc_mang([1, 2, 3, 4]))      # Output: [4, 3, 2, 1]
print(dao_nguoc_mang([10]))              # Output: [10]
print(dao_nguoc_mang([]))                # Output: []

9. Tìm Vị Trí Đầu Tiên

Dễ ⏱️ 5-10 phút

Bài toán:

Viết hàm vi_tri_dau_tien(arr, x) trả về vị trí xuất hiện đầu tiên của x. Nếu không có, trả về -1.

Ví dụ Input/Output:

print(vi_tri_dau_tien([3, 5, 7, 5], 5))   # Output: 1
print(vi_tri_dau_tien([1, 2, 3], 4))      # Output: -1
print(vi_tri_dau_tien([], 1))             # Output: -1

10. Thay Số Âm Bằng 0

print(thay_am_bang_0([3, -1, 5, -7]))   # Output: [3, 0, 5, 0]
print(thay_am_bang_0([-2, -8]))         # Output: [0, 0]
print(thay_am_bang_0([1, 2, 3]))        # Output: [1, 2, 3]

15. Dịch Trái Mảng 1 Bước

print(dao_nguoc_chuoi("python"))   # Output: nohtyp

print(dem_ky_tu("banana", "a"))   # Output: 3
print(dem_ky_tu("hello", "z"))    # Output: 0

Thử thách với các bài toán chuỗi đòi hỏi tư duy logic nhiều hơn

18. Kiểm Tra Palindrome

Trung bình ⏱️ 15-20 phút

Bài toán:

Viết hàm la_palindrome(s) trả về True nếu chuỗi s đọc xuôi và ngược giống nhau, ngược lại trả về False.

Ví dụ Input/Output:

print(la_palindrome("madam"))   # Output: True
print(la_palindrome("python"))  # Output: False
print(la_palindrome("a"))       # Output: True

19. Đếm Nguyên Âm Và Phụ Âm

Trung bình ⏱️ 15-20 phút

Bài toán:

Viết hàm dem_nguyen_am_phu_am(s) trả về một tuple (số nguyên âm, số phụ âm) trong chuỗi s (giả sử s chỉ gồm chữ cái).

Ví dụ Input/Output:

print(dem_nguyen_am_phu_am("hello"))   # Output: (2, 3)
print(dem_nguyen_am_phu_am("xyz"))     # Output: (0, 3)
print(dem_nguyen_am_phu_am("aeiou"))   # Output: (5, 0)
🔴 KHÓ

Bài tập Khó (20-21)

Các bài toán chuỗi nâng cao, kết hợp nhiều kỹ thuật xử lý

20. Kiểm Tra Anagram

Khó ⏱️ 25-30 phút

Bài toán:

Viết hàm la_anagram(s1, s2) trả về True nếu hai chuỗi là anagram của nhau (không phân biệt hoa/thường), ngược lại trả về False.

Ví dụ Input/Output:

print(la_anagram("listen", "silent"))         # Output: True
print(la_anagram("hello", "world"))           # Output: False
print(la_anagram("Dormitory", "dirtyroom"))   # Output: True

21. Nén Chuỗi (Run-Length Encoding)

Khó ⏱️ 25-30 phút

Bài toán:

Viết hàm nen_chuoi(s) nén các ký tự liên tiếp giống nhau thành ký tự kèm số lần lặp. Ví dụ "aaabbc" → "a3b2c1".

Ví dụ Input/Output:

print(nen_chuoi("aaabbc"))   # Output: a3b2c1
print(nen_chuoi("abc"))      # Output: a1b1c1
print(nen_chuoi(""))         # Output: (chuoi rong)
🟣 TỔNG HỢP

Bài tập Tổng hợp (22-26)

Kết hợp mảng với kiến thức đã học ở các chương trước: hàm, vòng lặp, cấu trúc điều kiện

22. Phân Loại Điểm Học Sinh

Tổng hợp ⏱️ 30-40 phút

Bài toán:

Viết hàm phan_loai_diem(scores) (Bài 5: Hàm) dùng vòng lặp (Bài 4) và cấu trúc điều kiện (Bài 2) để phân loại mảng điểm: Giỏi (≥8.0), Khá (≥6.5), Trung bình (≥5.0), Yếu (còn lại). Trả về dict đếm số lượng mỗi loại.

Ví dụ Input/Output:

print(phan_loai_diem([9, 7, 6, 4, 8.5, 5.5]))
# Output: {'Gioi': 2, 'Kha': 1, 'TB': 2, 'Yeu': 1}
print(phan_loai_diem([10, 10]))
# Output: {'Gioi': 2, 'Kha': 0, 'TB': 0, 'Yeu': 0}

23. Lọc Số Nguyên Tố Trong Mảng

Tổng hợp ⏱️ 30-40 phút

Bài toán:

Viết hàm phụ la_so_nguyen_to(n) (Bài 5: Hàm) kiểm tra số nguyên tố bằng vòng lặp (Bài 4, giống ví dụ "Số nguyên tố"), sau đó viết loc_so_nguyen_to(arr) gọi lại hàm trên để lọc các số nguyên tố trong mảng.

Ví dụ Input/Output:

print(loc_so_nguyen_to([4, 7, 10, 13, 15, 2]))   # Output: [7, 13, 2]
print(loc_so_nguyen_to([1, 4, 6, 8]))            # Output: []
print(loc_so_nguyen_to([2, 3, 5, 7]))            # Output: [2, 3, 5, 7]

24. Ước Chung Lớn Nhất Của Mảng

Tổng hợp ⏱️ 30-40 phút

Bài toán:

Viết hàm phụ uscln(a, b) (Bài 5: Hàm, giống ví dụ "Ước chung lớn nhất") rồi viết uscln_mang(arr) dùng vòng lặp (Bài 4) gọi lại hàm trên để tính USCLN của toàn bộ mảng.

Ví dụ Input/Output:

print(uscln_mang([12, 18, 24]))   # Output: 6
print(uscln_mang([7, 14, 21]))    # Output: 7
print(uscln_mang([5, 9]))         # Output: 1

25. Sắp Xếp Nổi Bọt (Bubble Sort)

Tổng hợp ⏱️ 30-40 phút

Bài toán:

Viết hàm sap_xep_noi_bot(arr) tự cài đặt thuật toán sắp xếp nổi bọt bằng vòng lặp lồng nhau (Bài 4) và điều kiện so sánh/hoán đổi (Bài 2), không dùng sort() hay sorted() có sẵn. Trả về mảng mới đã sắp xếp tăng dần.

Ví dụ Input/Output:

print(sap_xep_noi_bot([5, 2, 9, 1, 7]))   # Output: [1, 2, 5, 7, 9]
print(sap_xep_noi_bot([3, 3, 1]))         # Output: [1, 3, 3]
print(sap_xep_noi_bot([]))                # Output: []

26. Quản Lý Giỏ Hàng

Tổng hợp ⏱️ 30-40 phút

Bài toán:

Viết hàm xu_ly_gio_hang(actions) nhận vào mảng các hành động dạng tuple: ("them", ten, gia) để thêm sản phẩm hoặc ("xoa", ten) để xóa sản phẩm theo tên. Dùng vòng lặp (Bài 4) và điều kiện rẽ nhánh (Bài 2) để xử lý lần lượt từng hành động, trả về tổng tiền còn lại trong giỏ.

Ví dụ Input/Output:

print(xu_ly_gio_hang([("them", "Tao", 15000), ("them", "Sua", 20000), ("xoa", "Tao")]))
# Output: 20000
print(xu_ly_gio_hang([("them", "A", 10000), ("them", "B", 5000)]))
# Output: 15000
