1. How to Study

💡 Objective:

Understand the most effective way to study throughout the Code Up Your Brain course.

Study Principles:

Content is publicly available on the website
  • → You can review all theory, examples, and exercises anytime.
  • → Don't worry about "missing out" when absent.
Review theory and complete exercises after each session
  • → Programming is practice. Every line of code you write is progress.
Code along with the instructor
  • → Don't just watch, open Visual Studio and type along.
  • → When you type by hand, your brain truly learns.

Programming is not about memorizing, but understanding and doing.

2. Setting up Visual Studio Code (VS Code)

⚙️ Step 1: Download and Install

  1. Visit: https://code.visualstudio.com
  2. Choose the version suitable for your operating system (Windows / macOS / Linux).
  3. Install with default settings (Next → Next → Finish).

⚙️ Step 2: Install Python Extension

  1. Open VS Code
  2. Press Ctrl + Shift + X to open Extensions tab
  3. Search "Python" → select Python (by Microsoft) → Install

⚙️ Step 3: Verify Installation

  1. Open Terminal in VS Code (Ctrl + ~)
  2. Type:
python --version

If you see something like:

Python 3.12.2

→ You're ready to program! 🎉

3. Your First Program

🎯 Objective:

Run your first line of code and understand the "run program" process.

Step 1: Create new file

  • Go to File → New File
  • Save as hello.py

Step 2: Write the code:

print("Hello, Code up your brain!")

Step 3: Press Ctrl + F5 to run

Result:

Hello, Code up your brain!

Congratulations! You just wrote your first Python program.

4. Variables

💡 Concept:

Variables are "containers" that store data in memory. Each variable has:

  • Name
  • Value

Example:

name = "Minh"
age = 12
print("My name is", name)
print("I am", age, "years old")

⚙️ Variable Naming Rules:

  • Only contains letters, numbers, and underscore _
  • Cannot start with a number
  • Case sensitive

✅ Valid examples:

student_name = "An"
age2 = 13

❌ Invalid examples:

2name = "An"      # Error: starts with number
student-name = 12 # Error: contains dash

6. Practice Exercises

🧩 Exercise 1 – Greet the User

Write a program:

name = input("What's your name? ")
print("Hello,", name, "!")

🧩 Exercise 2 – Calculate Age

year = int(input("Your birth year: "))
age = 2025 - year
print("You are", age, "years old this year.")

🧩 Exercise 3 – Simple Calculator

Write a program that inputs two numbers and prints the results of addition, subtraction, multiplication, and division.

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

print("Sum:", a + b)
print("Difference:", a - b)
print("Product:", a * b)
print("Quotient:", a / b)

🧩 Exercise 4 – Small Challenge

Write a program that asks for name and age, then prints:

"Hello [Name], you have [100 - age] years left until you turn 100!"
