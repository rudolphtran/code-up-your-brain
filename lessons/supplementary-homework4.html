🌱 Easy Exercises

1. Count Odd Numbers from A to B

Easy ⏱️ 10-15 min

Problem:

Write a program that counts how many odd numbers exist in the range from A to B (inclusive).

Requirements:

  • Get two integers A and B from user input
  • Use a for loop to iterate through the range
  • Check if each number is odd (number % 2 != 0)
  • Display the total count of odd numbers
  • Handle cases where A > B by swapping values

Example:

Input: A = 1, B = 10
Output: There are 5 odd numbers (1, 3, 5, 7, 9)

Input: A = 10, B = 20
Output: There are 5 odd numbers (11, 13, 15, 17, 19)
💡 Hint

Use range(A, B+1) to include both endpoints. A number is odd if number % 2 != 0. Initialize a counter variable before the loop.

3. Sum of Numbers from A to B

Easy ⏱️ 10-15 min

Problem:

Write a program that calculates the sum of all numbers in the range from A to B (inclusive).

Requirements:

  • Get two integers A and B from user input
  • Use a for loop to iterate through the range
  • Calculate the sum of all numbers in the range
  • Display the sum result
  • Handle cases where A > B by swapping values

Example:

Input: A = 1, B = 5
Output: Sum = 15 (1+2+3+4+5)

Input: A = 10, B = 15

4. Count Numbers Divisible by 3

Requirements:

  • Get two integers A and B from user input
  • Use a for loop to iterate through the range
  • Check if each number is divisible by 3 (number % 3 == 0)
  • Display all numbers found and the total count
  • Handle cases where A > B by swapping values

💡 Hint

5. Count Digits in a Number

Easy ⏱️ 15-20 min

Problem:

Write a program that counts how many digits are in a positive integer using a loop.

Requirements:

  • Get a positive integer from user input
  • Use a while loop to count digits
  • Divide the number by 10 in each iteration
  • Display the total number of digits
  • Handle special case for 0 (has 1 digit)

Example:

Input: 12345
Output: Number of digits: 5

Input: 999
Output: Number of digits: 3

Input: 0
Output: Number of digits: 1
💡 Hint

Use integer division (//) to remove the last digit: number = number // 10. Count how many times you can divide before reaching 0. Handle the special case when input is 0.

  • Handle special case for 0 (sum is 0)

Use number % 10 to get the last digit, then divide by 10 using integer division (//). Keep a running sum and repeat until the number becomes 0.

7. Calculate Power Using Loop

Easy ⏱️ 15-20 min

Problem:

Write a program that calculates the power of a number (base^exponent) using only loops and multiplication. Do not use the ** operator or pow() function.

Requirements:

  • Get base and exponent from user input
  • Use a for loop to multiply the base by itself
  • Do NOT use ** operator or pow() function
  • Display the result
  • Handle special cases: exponent = 0 (result is 1), exponent = 1 (result is base)

Example:

Input: base = 2, exponent = 5
Output: 2^5 = 32

Input: base = 3, exponent = 4
Output: 3^4 = 81

Input: base = 5, exponent = 0
Output: 5^0 = 1
💡 Hint

Initialize result to 1. Use a for loop that runs 'exponent' times, multiplying result by base in each iteration. Remember that any number to the power of 0 is 1.

9. Count Words in a Sentence

Easy ⏱️ 15-20 min

Problem:

Write a program that counts the number of words in a sentence. Words are separated by spaces.

Requirements:

  • Get a sentence from user input
  • Use a for loop to iterate through each character
  • Count spaces and add 1 to get word count (or use split())
  • Handle multiple consecutive spaces correctly
  • Display the total word count

Example:

Input: "Hello world from Python"
Output: Number of words: 4

Input: "Programming is fun"
Output: Number of words: 3

Input: "Python"
Output: Number of words: 1
💡 Hint

The easiest way is to use the split() method which splits a string by spaces and returns a list. Then count the length of the list. Alternatively, count spaces and add 1 (but handle multiple spaces carefully).

10. Find All Divisors of a Number

Easy ⏱️ 15-20 min

Problem:

Write a program that finds and displays all divisors (factors) of a positive integer.

Requirements:

  • Get a positive integer from user input
  • Use a for loop to check all numbers from 1 to N
  • Check if each number divides N evenly (N % i == 0)
  • Display all divisors found
  • Count and display the total number of divisors

Example:

Input: 12
Output: Divisors: 1, 2, 3, 4, 6, 12
Total: 6 divisors

Input: 20
Output: Divisors: 1, 2, 4, 5, 10, 20
Total: 6 divisors

Input: 7
Output: Divisors: 1, 7
Total: 2 divisors (prime number)
💡 Hint

Use a for loop from 1 to N (inclusive). For each number i, check if N % i == 0. If true, i is a divisor. Store divisors in a list or print them directly.

11. Check Prime Number

Easy ⏱️ 15-20 min

Problem:

Write a program that checks whether a given positive integer is a prime number or not. A prime number is a number greater than 1 that has no divisors other than 1 and itself.

Requirements:

  • Get a positive integer from user input
  • Use a for loop to check for divisors from 2 to N-1
  • If any number divides N evenly, it's not prime
  • Display whether the number is prime or not
  • Handle special cases: numbers less than 2 are not prime

Example:

Input: 7
Output: 7 is a prime number

Input: 12
Output: 12 is not a prime number (divisible by 2, 3, 4, 6)

Input: 2
Output: 2 is a prime number

Input: 1
Output: 1 is not a prime number
💡 Hint

Start by checking if the number is less than 2 (not prime). Then use a for loop from 2 to N-1 to check if any number divides N evenly. If you find a divisor, the number is not prime. You can optimize by only checking up to the square root of N.

12. Sum of Odd Numbers from 1 to N

Easy ⏱️ 10-15 min

Problem:

Write a program that calculates the sum of all odd numbers from 1 to N (inclusive).

Requirements:

  • Get a positive integer N from user input
  • Use a for loop to iterate from 1 to N
  • Check if each number is odd (number % 2 != 0)
  • Add only odd numbers to the sum
  • Display the final sum of all odd numbers

Example:

Output: Sum of odd numbers = 25 (1+3+5+7+9)

Input: N = 15
Output: Sum of odd numbers = 64 (1+3+5+7+9+11+13+15)

Output: Sum of odd numbers = 9 (1+3+5)
💡 Hint

Initialize sum to 0. Use a for loop from 1 to N. For each number, check if it's odd using number % 2 != 0. If odd, add it to the sum. You can also use range(1, N+1, 2) to iterate only through odd numbers.

13. Sum of Squares from 1 to N

Easy ⏱️ 10-15 min

Problem:

Write a program that calculates the sum of squares of all numbers from 1 to N (1² + 2² + 3² + ... + N²).

Requirements:

  • Get a positive integer N from user input
  • Use a for loop to iterate from 1 to N
  • Calculate the square of each number (number * number or number ** 2)
  • Add each square to the running sum
  • Display the final sum of all squares

Example:

Input: N = 3
Output: Sum of squares = 14 (1² + 2² + 3² = 1 + 4 + 9)

Input: N = 5
Output: Sum of squares = 55 (1 + 4 + 9 + 16 + 25)

Input: N = 10
Output: Sum of squares = 385 (1 + 4 + 9 + 16 + 25 + 36 + 49 + 64 + 81 + 100)
💡 Hint

Initialize sum to 0. Use a for loop from 1 to N. In each iteration, calculate the square (i * i or i ** 2) and add it to sum. You can verify your answer using the formula: sum = N × (N + 1) × (2N + 1) / 6.
