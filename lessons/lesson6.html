1. Array là gì?

Trong Python, "array" ở mức cơ bản thường được học qua list (danh sách). Mảng là một tập hợp nhiều phần tử đặt trong cùng một biến, giúp lưu trữ và xử lý dữ liệu theo chỉ số.

Lợi ích khi dùng mảng

  • Gọn code: Không cần tạo nhiều biến rời rạc.
  • Dễ lặp: Duyệt dữ liệu bằng vòng lặp rất thuận tiện.
  • Dễ mở rộng: Có thể thêm, xóa, sắp xếp linh hoạt.
  • Ứng dụng rộng: Tính điểm, quản lý sản phẩm, thống kê dữ liệu,...

Ví dụ: Không dùng mảng vs Dùng mảng

❌ Không dùng mảng
score1 = 8
score2 = 9
score3 = 7
average = (score1 + score2 + score3) / 3
print(average)
✅ Dùng mảng (list)
scores = [8, 9, 7]
average = sum(scores) / len(scores)
print(average)
📦

2. Khởi tạo và truy cập phần tử

Cú pháp cơ bản

numbers = [10, 20, 30, 40, 50]
print(numbers[0])   # 10
print(numbers[2])   # 30
print(numbers[-1])  # 50 (phần tử cuối)

Chỉ số trong Python bắt đầu từ 0. Ví dụ phần tử đầu tiên là numbers[0], phần tử cuối có thể truy cập bằng numbers[-1].

💡 Lưu ý

Truy cập chỉ số vượt phạm vi sẽ gây lỗi IndexError. Luôn kiểm tra độ dài mảng khi cần.

🔁

3. Duyệt mảng và tính toán

Có hai cách phổ biến để duyệt mảng: duyệt trực tiếp từng phần tử hoặc duyệt theo chỉ số bằng range(len(array)).

Ví dụ: Tính tổng và đếm số chẵn

arr = [3, 6, 9, 10, 15, 20]

# Cách 1: duyệt phần tử
sum_arr = 0
even_count = 0
for value in arr:
    sum_arr += value
    if value % 2 == 0:
        even_count += 1

print("Tong:", sum_arr)        # 63
print("So chan:", even_count)   # 3

Ví dụ: Duyệt theo chỉ số

arr = [12, 7, 25, 4]
for i in range(len(arr)):
    print(f"arr[{i}] = {arr[i]}")
🛠️

4. Cập nhật mảng

Python list hỗ trợ nhiều thao tác cập nhật dữ liệu rất tiện lợi:

  • append(x): thêm phần tử vào cuối.
  • insert(i, x): chèn phần tử tại vị trí i.
  • remove(x): xóa phần tử có giá trị x đầu tiên.
  • pop(): xóa phần tử cuối và trả về giá trị đã xóa.
  • sort(): sắp xếp tăng dần tại chỗ.

Ví dụ cập nhật

products = ["apple", "banana", "orange"]

products.append("mango")
products.insert(1, "grape")
products.remove("banana")
last_item = products.pop()
products.sort()

print(products)   # ['apple', 'grape', 'orange']
print(last_item)  # mango
🔍

5. Tìm kiếm và thống kê

Khi làm việc với mảng, ta thường cần tìm phần tử lớn nhất/nhỏ nhất, kiểm tra sự tồn tại, hoặc đếm số lần xuất hiện của một giá trị.

Ví dụ tổng hợp

scores = [7, 9, 8, 9, 6, 10]

print("Max:", max(scores))         # 10
print("Min:", min(scores))         # 6
print("Co diem 8?", 8 in scores)   # True
print("So lan diem 9:", scores.count(9))  # 2

# Tim vi tri dau tien cua diem 9
idx = scores.index(9)
print("Vi tri diem 9 dau tien:", idx)  # 1

6. Practice Exercises

Bài tập 1: Tính tổng mảng

Viết chương trình nhận vào mảng số nguyên và in ra tổng các phần tử.

arr = [5, 10, 15, 20]
# TODO: in ra tong cua arr
💡 Show Solution 
arr = [5, 10, 15, 20]
print(sum(arr))  # 50

Bài tập 2: Tìm số lớn nhất

Cho mảng số nguyên, hãy in ra phần tử lớn nhất và vị trí của nó.

arr = [12, 6, 30, 18, 30]
# TODO: tim max va vi tri dau tien
💡 Show Solution 
arr = [12, 6, 30, 18, 30]
max_val = max(arr)
idx = arr.index(max_val)
print(max_val)  # 30
print(idx)      # 2

Bài tập 3: Lọc số chẵn

Tạo mảng mới chỉ chứa các số chẵn từ mảng ban đầu.

arr = [1, 2, 3, 4, 5, 6, 7, 8]
# TODO: tao mang chan
💡 Show Solution 
arr = [1, 2, 3, 4, 5, 6, 7, 8]
even_arr = []

for value in arr:
    if value % 2 == 0:
        even_arr.append(value)

print(even_arr)  # [2, 4, 6, 8]

🏆 Challenge: Quản lý điểm lớp học

Nhập một mảng điểm, sau đó in ra: điểm trung bình, điểm cao nhất, điểm thấp nhất, số lượng học sinh đạt từ 8.0 trở lên. 

scores = [6.5, 8.0, 9.2, 7.8, 8.7, 5.9]
# TODO: tinh thong ke theo yeu cau
💡 Show Solution 
scores = [6.5, 8.0, 9.2, 7.8, 8.7, 5.9]
avg = sum(scores) / len(scores)
best = max(scores)
worst = min(scores)
excellent_count = 0
for score in scores:
    if score >= 8.0:
        excellent_count += 1

print("Diem TB:", round(avg, 2))
print("Cao nhat:", best)
print("Thap nhat:", worst)
print("So hoc sinh >= 8.0:", excellent_count)
